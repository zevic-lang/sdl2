# snake

The classic game on a 32 x 20 grid. Arrow keys or WASD steer (the letter keys are recognised with `KeyName`). Until you press a key a small computer player steers: it heads for the food and avoids the walls and its own body. When the snake dies, Space starts a new game.

```
cd examples/snake
zevpm run
```

Needs the SDL2 development files; see the main README.
