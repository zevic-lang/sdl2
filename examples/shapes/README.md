# shapes

`Circle`, `FillCircle`, `Triangle` and `FillTriangle`: breathing rings, two spinning triangles and a ring of dots. Space switches between filled shapes and outlines, Escape quits. `Clock` keeps it at 60 frames a second and gives the time that moves the animation.

```
cd examples/shapes
zevpm run
```

Needs the SDL2 development files; see the main README.
